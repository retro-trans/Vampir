English translation of **Vampir: Kyuuketsuki Densetsu** for PlayStation (Artdink 1999), for the Japanese release (**SLPS-01932**).

Version v0.6.0 is the first public release: all of the game's text is translated.

### Apply

**The easiest way:** Using our tools [Retro Trans](https://github.com/retro-trans/retro-trans-tools) provides a desktop interface for applying translation patches. Download the app from its Releases page, choose **Automatic** tab, select your Track 1 `.bin`, wait for the app to analyze it then click Patch.

**Other ways**: [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) accepts the same `.xdelta` file. Select your unpacked Track 1 `.bin` as the original file and the patch.

**Command line**: Get [xdelta3 here](https://github.com/jmacd/xdelta). `chdman.exe` is included with [MAME](https://www.mamedev.org/release.html); you do not need to install or run MAME.

You need your own Japanese disc image as BIN/CUE with one file per track (Redump "Vampir - Kyuuketsuki Densetsu (Japan)"). The patch changes **Track 1 only**; Track 2 (audio) and the `.cue` file stay as they are.

| Your source image | Patch |
|---|---|
| Japanese release, SLPS-01932, Track 1 | `Vampir-Track1-English-v0.6.0.xdelta` |

```
xdelta3 -d -s "Vampir - Kyuuketsuki Densetsu (Japan) (Track 1).bin" Vampir-Track1-English-v0.6.0.xdelta "Vampir English v0.6.0 (Track 1).bin"
```

**Assemble the disc:** put the patched Track 1 in a new folder with copies of the original Track 2 `.bin` and `.cue`, and rename the patched file to the Track 1 name the `.cue` expects (`Vampir - Kyuuketsuki Densetsu (Japan) (Track 1).bin`). Open the `.cue` in your emulator.

**If you have a `.chd`**, unpack it first with one file per track, then apply the patch to the Track 1 `.bin`:

```
chdman extractcd -i "your-game.chd" -o "Vampir - Kyuuketsuki Densetsu (Japan).cue" --splitbin
```

If the patcher reports a checksum mismatch, check your Track 1 against the hashes in `README-v0.6.0.txt`. Do not disable source verification.

### What's in v0.6.0

* **All game text translated.** The villager conversations of all three stages (Medoekia, Calstatt and London), the story scenes, menus, status screens, the memory card screens and the name entry.
* **New English font.** A sharp variable-width Latin font built into the game's own text renderer, drawn from a 4x texture so upscaling emulators show crisp text. No emulator texture pack is needed.
* **Graphics redrawn in English.** Title logo, opening subtitles, Rose's poem, menu and status buttons, the nightfall save prompt and the staff credit role titles. Location banners such as "Go to the Medoekia" are the game's original English art.
* **English memory card saves.** Save titles read like `Vampir Chris STAGE1 D12 Morn` in the memory card manager and on the game's load screen. Names can be entered in Latin letters (up to 8).

The patch was decoded from the exact Japanese Track 1 and checked against the complete output SHA-256. Source/output hashes and the validation record are included in the release assets.

### Testing status

Checked in-game: opening, title screen, new game and name entry, prologue, Medoekia by day and night, menus and options, a partner conversation, a night encounter, the nightfall save prompt, saving and loading, and the Calstatt field. Not yet played through in English: the rest of Calstatt and London, and the endings; their text passes the automatic line-fit checks.

Fresh-boot the patched disc and load an in-game memory-card save when changing builds. Emulator save states keep the old executable and file positions and do not work across versions.

### What's included

A full patch from the Japanese Track 1. Track 2 and the `.cue` file are not patched. There are no upgrade patches yet, since this is the first release.

### How it was translated

This is a **machine translation**, produced with large language models and then edited, rather than a hand translation by a fluent translator. Names and terminology follow the game's own English graphics and community references.
