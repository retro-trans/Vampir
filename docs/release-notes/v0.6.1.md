English translation of **Vampir: Kyuuketsuki Densetsu** for PlayStation (Artdink 1999), for the Japanese release (**SLPS-01932**).

Version v0.6.1 fixes a crash when viewing a Nosferatu's status and translates text that v0.6.0 missed.

### Apply

**The easiest way:** Using our tools [Retro Trans](https://github.com/retro-trans/retro-trans-tools) provides a desktop interface for applying translation patches. Download the app from its Releases page, choose **Automatic** tab, select your Track 1 `.bin`, wait for the app to analyze it then click Patch.

**Other ways**: [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) accepts the same `.xdelta` files. Select your unpacked Track 1 `.bin` as the original file and the appropriate patch.

**Command line**: Get [xdelta3 here](https://github.com/jmacd/xdelta). `chdman.exe` is included with [MAME](https://www.mamedev.org/release.html); you do not need to install or run MAME.

You need your own Japanese disc image as BIN/CUE with one file per track (Redump "Vampir - Kyuuketsuki Densetsu (Japan)"), or the published English v0.6.0 Track 1 for an upgrade. The patches change **Track 1 only**; Track 2 (audio) and the `.cue` file stay as they are.

| Your source image | Patch |
|---|---|
| Japanese release, SLPS-01932, Track 1 | `Vampir-Track1-English-v0.6.1.xdelta` |
| English v0.6.0, Track 1 | `Vampir-Track1-English-v0.6.0-to-v0.6.1.xdelta` |

```
xdelta3 -d -s "Vampir - Kyuuketsuki Densetsu (Japan) (Track 1).bin" Vampir-Track1-English-v0.6.1.xdelta "Vampir English v0.6.1 (Track 1).bin"
```

**Already on v0.6.0?** Use the smaller upgrade patch on your patched Track 1:

```
xdelta3 -d -s "Vampir English v0.6.0 (Track 1).bin" Vampir-Track1-English-v0.6.0-to-v0.6.1.xdelta "Vampir English v0.6.1 (Track 1).bin"
```

**Assemble the disc:** put the patched Track 1 in a new folder with copies of the original Track 2 `.bin` and `.cue`, and rename the patched file to the Track 1 name the `.cue` expects (`Vampir - Kyuuketsuki Densetsu (Japan) (Track 1).bin`). Open the `.cue` in your emulator.

**If you have a `.chd`**, unpack it first with one file per track, then apply the patch to the Track 1 `.bin`:

```
chdman extractcd -i "your-game.chd" -o "Vampir - Kyuuketsuki Densetsu (Japan).cue" --splitbin
```

If the patcher reports a checksum mismatch, check your Track 1 against the hashes in `README-v0.6.1.txt`. Do not disable source verification. The upgrade patch requires the exact published v0.6.0 output. Full and upgrade patches produce identical v0.6.1 output.

### What changed since v0.6.0

* **Nosferatu status crash fixed.** Viewing a Nosferatu in the status menu crashed the game: the English age text overflowed a small buffer and overwrote the selected villager. The age now shows as a number next to the Age label. The build now checks every text the game joins into a fixed buffer.
* **Drain screen translated.** The "Drain" banner and the Blood Used, Drain Power, ND Progress, Morality, Affinity, Strength, Intellect and Charm labels were blank. Labels are right-aligned to their numbers as in the Japanese layout.
* **Building and place names translated.** All 221 names shown on the banner when you enter a building ("House", "Church", "Café Jahn", "Tower of London", …) were blank.
* **Stage names translated.** The field label showed nothing outside named areas in Calstatt and London.

The patches were decoded from their exact source Track 1 and checked against the complete output SHA-256. Source/output hashes and the validation record are included in the release assets.

### Testing status

Checked in-game: the drain screen with all labels, the "House" banner and "Drink from whom?" prompt, saving and loading, and the status text builder (the selected villager is no longer overwritten). The Nosferatu status screen itself, the Calstatt and London stage names and the London building names have not yet been seen on screen. Not yet played through in English: the rest of Calstatt and London, and the endings.

Memory card saves from v0.6.0 load in v0.6.1. Emulator save states do not work across versions: fresh-boot the patched disc and load a memory-card save.

### What's included

A full patch from the Japanese Track 1 and an upgrade patch from the exact published v0.6.0 Track 1. Track 2 and the `.cue` file are not patched.

### How it was translated

This is a **machine translation**, produced with large language models and then edited, rather than a hand translation by a fluent translator. Names and terminology follow the game's own English graphics and community references.
